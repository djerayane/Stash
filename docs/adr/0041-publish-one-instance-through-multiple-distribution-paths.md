# Publish one Instance through multiple distribution paths

Stash publishes the same server core and web application as a multi-architecture OCI image and as checksummed standalone server bundles that do not require a local Node or pnpm toolchain. The supported source-based baseline remains Docker Compose with one Stash application container and PostgreSQL, and a fresh checkout supplies clearly marked localhost-only defaults so `docker compose up` starts an evaluable Instance without prior configuration. Standalone bundles still require PostgreSQL and the same production configuration; they do not create an embedded or local-only storage model. Canonical semantic-version releases may also produce signed Expo mobile artifacts that connect directly to a Member-supplied HTTPS Instance. One complete release-quality gate verifies every artifact path, and every publisher depends on it. A Git tag selects a source revision but is not itself treated as immutable: collision and ref checks fail closed, while recorded OCI and SHA-256 digests remain the permanent artifact identities even if a tag is later moved.
