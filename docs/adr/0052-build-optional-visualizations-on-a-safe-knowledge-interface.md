# Build optional visualizations on a safe knowledge interface

Stash makes the Note Tree, breadcrumbs, outgoing links, backlinks, broken-link maintenance, and focused related-Note navigation part of the core product, while global graphs, semantic brain maps, word clouds, and freeform canvases remain optional lenses. Visualization Blocks use a stable internal interface and portable saved-view format over server-side permission-filtered neighborhood, search, facet, and aggregate queries; typed Note Links are optional, view-only edges and geometry never mutate canonical knowledge without explicit promotion, every visualization has an equivalent navigable list, outline, or table, and third-party execution remains deferred until plugin sandboxing, permissions, compatibility, and export behavior are deliberately designed.
