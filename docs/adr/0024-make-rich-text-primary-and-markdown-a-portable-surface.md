# Make rich text primary and Markdown a portable surface

Members author Notes through a familiar WYSIWYG editor with direct formatting, selection, paste, undo, keyboard navigation, and insert controls rather than being required to know Markdown. Supported rich constructs retain documented Markdown representations, and optional source editing serves power users; features that cannot round-trip intelligibly must remain separate Workspace objects or use deliberate documented extensions instead of hiding essential content in an opaque editor format.
