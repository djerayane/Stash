# Provide distinct portable exports and Instance Backups

A Portable Workspace Export preserves every durable domain object, property, relationship, history item, permission definition, and Attachment in versioned, documented formats without secrets; importing elsewhere preserves missing people as Identity Stubs that an Admin may explicitly map. A separately integrity-checked Instance Backup supports exact restoration of accounts, identity links, permissions, configuration, audit records, and encrypted integration credentials, with automated round-trip tests enforcing both contracts.
