# Make first-run setup personal and browser-guided

The first-run journey creates a personal account and personal Workspace, introducing Organizations only when the Member deliberately expands into collaborative work. Setup happens in the browser with only essential identity and Workspace fields, then teaches the product inside a small, disposable branch of real Notes, Collections, View Blocks, and Tasks; an Instance reached through localhost may be claimed directly, while any non-local Instance requires a short-lived one-time setup code shown in its startup output so an unknown network visitor cannot claim it first. When a Member has only one personal Workspace, the shell presents Notes, Tasks, and Projects directly; Workspace switching and Organization administration appear only when those concepts become relevant.
