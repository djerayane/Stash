# Target large single-node Instances before horizontal scale

The first stable release prioritizes small installations while testing a supported single-Instance envelope of 1,000 active Members, 100 Organizations, 10,000 Projects, one million Notes and Tasks, 100 concurrent editing sessions, ten million searchable Blocks, and one terabyte of Attachments with external object storage. Representative benchmarks make these limits falsifiable, and larger deployments remain explicitly unverified rather than implying effortless horizontal scaling.
