# Separate operational storage from the portable Workspace projection

Stash may use structured internal storage as the operational authority for reliable collaboration while continuously producing a documented portable representation. Notes and Tasks project to Markdown, Attachments to files with relative links, and other durable objects to documented JSON or YAML with readable reports where useful; generated indexes remain disposable, complete exports round-trip without domain-data loss, and external file edits enter through explicit import and reconciliation rather than pretending arbitrary editors share the live collaboration protocol.
